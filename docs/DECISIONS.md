## D-14. 고양이 모델 방식
1. 코드로 만든 로우폴리 고양이 + 절차적 애니메이션 (권장) — 라이선스 문제 없음, 털색·무늬·그루밍 자유. 대신 사실감은 낮다
2. 무료(CC0 등) 리깅 모델 탐색 — 더 고양이 같지만 그루밍·앉기 동작이 없을 가능성이 높고, 라이선스 확인과 검색에 시간이 든다
3. 혼합 (사실성 보강안): 무료 리깅 모델을 시간 제한을 두고 탐색하고, 없으면 고급화한 코드 모델로 진행. 모델을 교체할 수 있는 구조로 설계 — 상세: 04 보고서 부록 A
