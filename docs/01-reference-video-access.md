# 01. 참조 영상 접근 기록 및 1차 확인 사실

- 작성일: 2026-11-03
- 근거 문서: `docs/README.md` (2장 작업 원칙, 7장 보고서 1번 항목)

## 1. 접근 결과 요약

| 항목 | 결과 | 방법 |
|---|---|---|
| 영상 메타데이터 | 확인 | YouTube oEmbed / 공개 페이지 |
| 영상 본편 재생(움직임) | **미확인** | `yt-dlp` 미설치. 공개 스트림을 `curl`로 직접 받는 시도는 Claude Code 권한 정책(웹사이트 접근 우회 방지)에서 거부됨 |
| 오디오(음악, 효과음, 울음소리) | **미확인** | 위와 동일 |
| 장면 구성 | 부분 확인 | YouTube 공개 스토리보드: 1초 간격 26프레임, 프레임당 101×180px |
| 대표 썸네일 | 확인 | `maxresdefault.jpg` (1280×720, 세로 영상에 블러 배경) |

확인용 이미지는 저작권 자료이므로 저장소에 넣지 않고 세션 임시 폴더에만 두었다.

## 2. 메타데이터 (확인된 사실)

- 제목: 오늘도 혼자 산책하는 수다 고양이의 하루 3탄 ㅋㅋ
- 채널: 꿀잼식빵
- 길이: 25초, YouTube Shorts (세로 9:16)
- 설명란: 비어 있음
- 화면 상단 고정 타이틀: "혼자 산책하는 / 수다냥이의 일상 3탄ㅋㅋ" (흰 배경 레터박스 위 텍스트)

## 3. 스토리보드에서 확인한 사실

> 해상도가 매우 낮아 **자막 문구 일부는 정확하지 않을 수 있다.** 불확실한 문구는 `(?)`로 표시했다.

### 3.1 형식에 관한 사실
- **실사 영상**이다. 3D/2D 그래픽이 아니다.
- **고양이 몸(목/가슴 부근으로 추정)에 부착된 카메라의 1인칭 시점**이다. 화면 하단에 흰 고양이의 앞발·가슴 털이 반복적으로 보이고, 시선이 지면을 향한다.
- 고양이는 흰색(일부 장면에서 회색/검은 무늬가 보이나 같은 개체인지는 미확인).
- 편집: 하단 흰 자막(내레이션 형식) + 노란 말풍선형 효과 자막(고양이 대사/의성어).

### 3.2 초 단위 장면 흐름 (스토리보드 기준, 0~25초)

| 초 | 화면 | 자막(판독) |
|---|---|---|
| 0–3 | 아스팔트 위 흰 앞발, 도로 흰 선 | "까꿍~", "오늘도 혼자 산책을 나온 수다냥(?)" |
| 4–5 | 지면에 비친 **고양이 자신의 그림자** | "우와아앙~", "본인 그림자 감상 중/후(?)" |
| 6–9 | 하늘, 주차된 **자동차 옆면·바퀴**, 횡단보도, 간판 | 판독 불가 |
| 10 | 철망/울타리 그림자가 진 바닥, 앞발 | 판독 불가 |
| 11–12 | **분홍색 꽃**을 가까이에서 봄 | "꽃 구경도 하고", "뭉?" |
| 13–14 | **풀/클로버** 덤불 | "오흥흥~", "풀도 감상하고" |
| 15–19 | 아스팔트, 앞발, 그림자 | "아오오오오오~~"(울음), "자기 목소리를 자랑하고 다닌다 ㅋㅋ" |
| 20–21 | 어두운 그림자 / 사람 신체 일부로 보이는 장면 | "그러다 결국", "집사한테 걸려(?)" |
| 22–25 | 타일 바닥, 고양이 등·꼬리, 바구니 같은 구조물(집 근처로 추정) | "오늘도 빨리 잡혀서 ~(?)", 노란 태그 "꼬리흔들(?)" |

### 3.3 아직 확인하지 못한 것
- 실제 오디오: 배경음악 유무, 실제 울음소리("아오오~"가 실제 소리인지 자막 연출인지), 환경음
- 카메라 흔들림 정도, 걷는 속도·리듬
- 장면 사이 컷 편집 방식 (연속 촬영인지, 여러 클립을 이은 것인지)
- 마지막 장면의 맥락 (집사에게 잡혀 귀가하는 것인지)

## 4. 1차 시사점 (해석 — 사실 아님)

아래는 확인된 사실을 바탕으로 한 **추정과 해석**이며, 전체 영상 확인 후 수정될 수 있다.

1. 영상의 매력은 "예쁜 고양이 외모"보다 **"고양이 눈높이에서 본 평범한 동네"**와 **"고양이 속마음을 대신 말해 주는 자막"**에 있는 것으로 보인다.
2. 기존 기획의 "3인칭 추적 카메라 + 3D 마을/숲"과는 **카메라 시점과 매체 자체가 다르다.** 이 차이를 어떻게 다룰지가 컨셉 재정의의 핵심 쟁점이 될 가능성이 높다.
3. 장소는 판타지 세계가 아니라 **현실적인 주거 골목**(아스팔트, 주차된 차, 횡단보도, 화단)이다.
4. "혼자 나간 산책 → 작은 발견(그림자, 꽃, 풀) → 수다 → 집사에게 잡혀 귀가"라는 **짧은 하루 루프** 구조가 보인다.
