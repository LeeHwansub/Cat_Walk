## 확정된 방향
- 그래픽: 부드러운 사실풍 (사진 수준 실사 X, 잘 만든 3D 게임 수준)
- 고양이 2종(브라운 태비 / 치즈 태비 스코티시폴드)은 커스터마이징 프리셋으로 추가
- 모바일: 모바일 브라우저에서 플레이 가능 + 모바일 전용 터치 컨트롤러
- 배경: 한국 주택가 골목 (이후 다른 공간 확장 예정)
- 서버, 계정, 기기 간 동기화는 이번 범위가 아님

## 작업 원칙
- 먼저 현재 코드 구조를 확인하고 보고한 뒤 진행
- 특히 고양이 모델이 기본 도형 조합인지, 뼈대가 있는 3D 모델인지 먼저 보고
- 모델 교체 같은 대규모 구조 변경, 외부 에셋 도입은 승인 후 진행 (라이선스 확인 필수)
- 단계별로 실행 가능한 상태를 유지

## 1단계: 버그성 수정 (먼저)
### 6. 앉은 채로 걷기 금지
- 이동은 걷기 상태에서만 허용
- 앉기/눕기 상태에서 이동 입력이 오면: 일어서기 동작(0.3~0.5초) → 걷기 순서로 전환
- 이동 속도와 애니메이션 상태가 항상 일치하도록 상태 관리

### 5. 먹이 먹는 동안 이동 금지
- 흐름: 그릇으로 다가가기 → 냄새 맡기 → 먹기(5~8초) → 입 핥기 → 조작 해제
- 먹는 동안 이동 입력은 무시하되 카메라 회전과 줌은 허용
- 먹는 중 이동 키를 누르면 귀 움찔 같은 작은 반응만

## 2단계: 캐릭터
### 1. 고양이 디테일
- 실루엣: 접힌 귀, 둥근 머리와 볼살, 큰 눈, 통통한 몸, 짧은 다리
- 프리셋 A 브라운 태비: 이마 M자 무늬, 몸통 고등어 줄무늬, 흰 양말 발, 꼬리 고리 무늬와 진한 끝, 분홍 하트 목걸이 태그, 황록색 눈
- 프리셋 B 치즈 태비: 크림/주황 바탕, 주황 줄무늬, 꼬리 고리 무늬, 황록색 눈
- 눈: 각막 반사와 하이라이트로 촉촉한 느낌
- 털: 데스크톱은 shell fur(여러 겹 레이어), 모바일은 가벼운 텍스처 방식
- 살아있는 느낌: 눈 깜빡임, 숨쉬기, 귀 움찔, 꼬리 살랑, 주변을 바라보는 고개 돌림

### 7. 포즈 추가
- 식빵 자세, 옆으로 눕기, 배 보이고 눕기, 기지개, 꼬리 감고 엎드리기
- 스코티시폴드 특유의 '아저씨 앉기'(엉덩이를 대고 사람처럼 앉는 자세)
- 자율 행동에 사용하고, 사진 모드에서도 선택 가능하게

### (추가) 성장 단계 + 크기 조절
- 성체 / 아기고양이는 기존처럼 버튼으로 선택
- 버튼 아래에 크기 조절 바(슬라이더)를 추가해 단계 안에서 크기를 세밀하게 조절
  - 기본값 100%, 범위는 단계별로 제한 (예: 아기 80~110%, 성체 85~120%)
  - 바를 움직이면 생성 화면 미리보기에 즉시 반영
- 아기와 성체는 크기만 다른 게 아니라 비율도 다르게 표현
  - 아기: 머리와 눈이 몸에 비해 크고, 다리와 꼬리가 짧고, 털이 더 보송함
  - 성체: 보내준 참고 사진의 비율
- 크기에 맞춰 함께 조정할 것
  - 이동 속도와 걸음 간격 (작을수록 종종걸음)
  - 카메라 거리와 높이
  - 충돌 범위 (차 밑, 필로티 밑 등 낮은 공간 통과 판정)
  - 울음소리 음높이 (작을수록 약간 높게)
- 선택한 성장 단계와 크기 값은 로컬에 저장해서 새로고침 후에도 유지

## 3단계: 월드
### 2. 건물 디테일 (한국 주택가 골목)
- 필로티 빌라, 에어컨 실외기, 화분, 전봇대와 전선, 담벼락, 우편함, 계단, 창틀, 난간
- 벽 얼룩 같은 낡은 디테일
- 재사용 가능한 모듈형 부품으로 제작

### 3. 고양이 이동 경로 (차 밑, 필로티 밑)
- 낮은 공간에서는 몸을 낮춰 기어가는 걷기 동작 사용 (6번의 버그와는 다른 의도된 동작)
- 카메라가 차나 천장을 뚫지 않게 충돌 처리, 낮은 공간에서는 가까이·낮게 자동 조정
- 자율 모드에서도 가끔 차 밑에 숨어 쉬는 행동 추가

### 4. 맵 확장
- 구역 단위 연결: 골목 → 필로티 주차장 → 놀이터 → 공원·숲
- 가까운 구역만 불러오는 방식으로 모바일 성능 확보

## 4단계: 기능
### 8. 스크린샷 저장
- 사진 모드: UI 숨김, 자유 카메라, 포즈 선택, 저장 버튼
- 모바일은 공유 기능(Web Share API)으로 앨범 저장/메신저 공유

### 9. 모바일 대응
- 왼쪽 가상 조이스틱으로 이동, 드래그로 카메라 회전, 두 손가락 핀치 줌
- 먹이 주기, 사진 모드 등 주요 동작은 터치 버튼으로
- 기기 성능에 따라 그래픽 품질 자동 조절 (털 레이어 수, 그림자 품질)
- PWA로 홈 화면 추가 지원

## 1단계 결과 (2026-11-05)

### 현재 구조 보고 요약
- 고양이 모델: **기본 도형(구·캡슐·원뿔) 조합 + 코드 IK**. 뼈대(`SkinnedMesh`/`Bone`)나 3D 모델 파일(glTF)은 없다.
- 행동(무엇을) `behavior/` → 자세 값 `CatAnimator` → 모델 적용 `CatRig` 로 분리되어 있어, 모델만 교체할 수 있다.

### 6번 앉은 채로 걷기 금지
- `cat/posture.ts`: 앉기·엎드리기 정도가 0.12를 넘으면 이동 불가.
- 이동이 필요한데 앉아 있으면 그 프레임은 멈추고 "일어서기"를 요청한다. 일어서기 속도는 앉은 자세에서 약 0.35초(테스트로 0.3~0.5초 보장).
- 자율 이동, 직접 조작, 그릇으로 가기, 냄새 맡을 때 몸 돌리기 모두 같은 규칙을 거친다. 일어서기는 쓰다듬기 반응보다 우선한다.

### 5번 먹이 먹는 동안 이동 금지
- `systems/eating.ts` `EatingSequence`: 다가가기 → 냄새 맡기(1초) → 먹기(5~8초) → 입 핥기(1.2초) → 끝.
- 도착 후부터 끝날 때까지 이동 입력 무시, 키를 새로 누르면 귀 움찔(0.6초 간격 제한). 카메라 회전·줌은 그대로.
- **판단한 부분:** 그릇으로 "다가가는 중"에는 잠그지 않았다. 이동 키를 누르면 먹기를 취소하고 사용자 조작을 따른다 (그릇은 남는다).
- 직접 조작 모드에서도 먹이 주기가 동작하고, 배고플 때 그릇 앞까지 걸어가면 먹기가 시작된다.
- 먹는 중에 쓰다듬으면 골골송만 나고 자세는 바뀌지 않는다.

### 검증
- 단위 테스트 59개 통과 (일어서기 시간, 이동 차단 기준, 먹기 단계·시간·1회 알림 등 13개 추가), 타입 검사, 빌드 통과.
- headless Chrome 측정: 앉은 상태에서 이동한 샘플 0회 (직접 조작·자율 모두), 먹는 중 W 1.5초 → 이동 0m·귀 움찔, 단계 순서 approach>sniff>eat>lick>done, 다가가는 중 입력 시 취소.
