## 1. 핵심 판단: 지금 모델로 목표 품질에 닿을 수 있는가

목표는 "부드러운 사실풍, 잘 만든 3D 게임 수준"이다 (참고: _Stray_ 스크린샷의 품질 수준).

| 항목 | 현재 도형 모델로 가능한가 (추정) |
|---|---|
| 접힌 귀, 둥근 머리·볼살, 큰 눈, 통통한 몸, 짧은 다리 | 가능 (비율 조정) |
| 무늬: 이마 M자, 고등어 줄무늬, 흰 양말, 꼬리 고리·진한 끝 | 대부분 가능 (부위별 텍스처). 무늬가 부위 경계에서 끊김 |
| 촉촉한 눈 (각막 반사·하이라이트) | 가능 (투명 각막 + 반사 재질) |
| shell fur (털 여러 겹) | 가능. 다만 도형 이음새에서 털이 겹치거나 비는 부분이 생김 |
| 포즈 6종 (식빵, 옆으로 눕기, 배 보이고 눕기, 기지개, 꼬리 감고 엎드리기, 아저씨 앉기) | 가능 (자세 값 + IK + 몸 전체 회전) |
| **매끈하게 이어진 몸, 근육·관절 변형, "잘 만든 3D 게임" 수준** | **어렵다.** 도형을 붙인 구조라 관절에서 이음새가 보이고 장난감 느낌이 남는다 |

**정리:** 목표 품질에 닿으려면 결국 **뼈대가 있는 하나로 이어진 고양이 모델(리깅된 메시)**이 필요하다고 판단한다. 다만 모델 교체는 대규모 변경이고 외부 에셋 또는 제작이 필요하므로 승인 대상이다.

## 2. 진행 방안 (D-23)

| 방안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| A. 도형 모델 고도화 | 지금 모델을 다듬어 위 항목 구현 | 바로 진행, 라이선스 문제 없음 | 품질 상한이 낮다 (장난감 느낌) |
| B. 리깅 모델로 교체 | 스코티시폴드 리깅 모델 확보 → `SkinnedCatRig`로 교체 | 품질 상한이 높다 | 모델 확보가 선행 조건 (구매 승인 또는 제작). 기간 불확실 |
| **C. 단계적 (권장)** | 모델과 무관한 작업을 먼저 하고, 동시에 B 후보를 조사해 승인받으면 교체 | 작업이 멈추지 않고, 만든 기능 대부분을 교체 후에도 재사용 | 무늬 텍스처는 교체 시 다시 만들어야 함 |

모델을 바꿔도 재사용되는 부분: 행동·자세 시스템(`behavior/`, `CatAnimator`, `CatPose`), 포즈 데이터, 크기·비율 연동, 털 셰이더 구조, 품질 옵션. 기존 설계에서 모델을 `CatRig` 인터페이스 뒤로 분리해 둔 덕분이다.

### B 모델 확보 경로 (C를 고르면 병행 조사, 조사까지만 하고 구매·다운로드는 승인 후)
1. 유료 리깅 고양이 모델 구매 후 귀 수정 — 라이선스(상업적 이용·수정) 확인 필수
2. Blender로 직접 제작 또는 외주 — 뽀리·레오 시트를 기준으로 제작, 소유권 명확
3. AI 3D 생성 서비스로 형태 생성 후 리깅 — 이용약관 확인 필요, 네발짐승 리깅은 수작업

## 3. 모델과 무관하게 먼저 할 작업 (C-1, 승인 시 이 순서로 진행)

| 순서 | 작업 | 내용 | 예상 (추정) |
|---|---|---|---|
| 1 | 성장 단계 + 크기 조절 | 생성 화면 슬라이더(아기 80~110%, 성체 85~120%, 기본 100%), 즉시 미리보기. 아기 비율(머리·눈 크게, 다리·꼬리 짧게, 털 보송). 크기에 따라 이동 속도·걸음 간격·카메라 거리·높이·충돌 반경·울음 음높이 연동. 로컬 저장 | 0.5일 |
| 2 | 프리셋 A·B (뽀리·레오) | 기존 프리셋 5종 유지 + 2종 추가. 귀 형태(선 귀/접힌 귀) 옵션. 무늬: 이마 M자, 고등어 줄무늬, 흰 양말, 꼬리 고리·진한 끝, 분홍 하트 목걸이 태그(뽀리), 황록색 눈 | 0.5일 |
| 3 | 포즈 6종 | 자세 값 확장으로 식빵, 옆으로 눕기, 배 보이고 눕기, 기지개, 꼬리 감고 엎드리기, 아저씨 앉기. 자율 행동에 연결 (사진 모드 선택은 4단계) | 1일 |
| 4 | 눈·살아있는 느낌 | 각막 반사·하이라이트 재질, 관심 지점을 바라보는 고개 돌림 (깜빡임·숨쉬기·귀·꼬리는 이미 있음) | 0.3일 |

각 작업 끝마다 테스트(단위 + 브라우저 캡처)와 보고를 한다.

## 4. 위험과 대응
- shell fur 성능: 겹 수를 품질 설정으로 조절하고, 모바일은 텍스처만 쓴다.
- 도형 이음새: 털이 일부 가려 주지만 근본 해결은 B.
- 참고 이미지(_Stray_)의 캐릭터 디자인(가방, 네온 분위기)은 가져오지 않는다. 품질 수준만 참고한다.
