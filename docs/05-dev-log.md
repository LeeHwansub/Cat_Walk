## 1. 실행 방법

```bash
cd web
npm install          # 처음 한 번
npm run dev          # 개발 서버 (http://localhost:5173)
npm test             # 단위 테스트 (Vitest)
npm run typecheck    # 타입 검사
npm run build        # 타입 검사 + 프로덕션 빌드 (web/dist)
npm run preview      # 빌드 결과 미리보기 (http://localhost:4173)
```

조작: WASD·방향키 이동 / 마우스 드래그 카메라 회전 / 휠 줌 / `C` 고양이 시점 전환 / `F` 먹이 주기 / 고양이 클릭 쓰다듬기 / `Esc` 설정

## 2. 설치한 의존성 (D-13 승인 범위)

| 패키지 | 버전 | 용도 |
|---|---|---|
| three | 0.187.0 | 3D 렌더링 |
| @types/three | 0.187.0 | 타입 |
| vite | 8.3.5 | 개발 서버·빌드 |
| vitest | 5.1.0 | 단위 테스트 |
| typescript | 5.9.3 | 타입 검사 |

- TypeScript는 최신 7.x 대신 **5.9.3**으로 고정했다. 04 보고서에서 "7.x와 Vite 도구 호환성 미확인"을 위험으로 적었고, 처음부터 안정 버전을 쓰는 쪽을 택했다.
- `~/.npm` 캐시 폴더에 root 소유 파일이 있어 npm 설치가 권한 오류로 실패했다. npm이 안내하는 `sudo chown`은 시스템 권한 변경이라 실행하지 않고, 세션 임시 폴더를 캐시로 지정해 설치했다(`--cache`). 사용자 환경에서 `npm install`이 같은 오류를 내면 아래 명령으로 해결할 수 있다 (사용자가 직접 실행):
  `sudo chown -R $(id -u):$(id -g) ~/.npm`

## 3. 구조

```
web/src/
├─ main.ts                 진입점
├─ game.ts                 시스템 연결, 자율 행동 실행, 모드 전환, 저장 주기
├─ core/                   input(키보드), rng(시드 난수)
├─ behavior/               types, selector(가중치 선택), brain(행동 상태)   ← 순수 로직, 테스트 대상
├─ cat/                    appearance, pose, rig(인터페이스), ProceduralCatRig(모델), CatAnimator(행동→자세), CatController(이동), ik
├─ camera/                 CameraRig (눈높이 3인칭 + 캣캠)
├─ world/                  scene(조명·그림자), collision(2D 충돌), textures, map/neighborhood(골목+공원)
├─ systems/                hunger, food(그릇), npc(주민)
├─ audio/                  AudioManager (Web Audio 합성음)
├─ save/                   storage (localStorage, 검증·손상 대비)
└─ ui/                     ui.ts, styles.css
web/tests/                 selector, brain, hunger, storage, collision, ik
```

설계 포인트
- **행동(무엇을)과 움직임(어떻게)의 분리:** `behavior/`는 행동만 고르고, `CatAnimator`가 행동을 자세 값(`CatPose`)으로 바꾸고, `CatRig`가 자세를 모델에 적용한다.
- **모델 교체 가능 (D-14):** `CatRig` 인터페이스만 구현하면 리깅된 glTF 모델로 바꿀 수 있다. 행동·애니메이터 코드는 그대로 쓴다.
- **다리 IK:** 발 위치를 정하면 관절 각도를 계산한다. 서기·앉기·엎드리기·걷기·그루밍 모두 발이 지면이나 목표(입, 얼굴)에 닿는다. 걷기 위상은 이동 거리로 진행해 발 미끄러짐을 줄였다.
- **자율 행동 로직 (기획서 5.4):** 무작위가 아니라 가중치 선택이다. 직전 행동 감점, 쿨다운(그루밍 40초, 낮잠 120초), 활동 시간 누적에 따른 휴식 증가, 주변 관심 지점(화분·풀·차·햇볕 자리·먹이)에 따른 가중치가 반영된다.

## 6. 남은 문제와 제한 사항

- **소리 파일의 출처·라이선스가 확인되지 않았다 (D-19).** 외부 공개 전에 확인해야 한다.
- **고양이 모델의 사실성:** 도형 기반이라 반사실적 수준이다. 털 질감(셸 텍스처링)은 넣지 않았다.
- **캣캠의 앞발:** 걸을 때 화면 하단에 잠깐씩 보이는 정도다. 드래그로 시선을 조정할 수 있다.
- **충돌 단순화:** 고양이는 담장·차 위로 올라가지 못하고, 차 밑으로도 못 들어간다.
- **경로 탐색 없음:** 자율 이동은 직선 이동이다. 막히면 1.5초 뒤 다른 행동으로 넘어간다.
- **실제 GPU·모바일 미확인:** 점검은 headless Chrome 소프트웨어 렌더링에서만 했다. 성능(FPS)은 측정하지 않았다.
- **커밋하지 않음:** `web/` 코드와 이 문서는 아직 미커밋이다.
