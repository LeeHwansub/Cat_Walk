## 2. 가장 중요한 작업 원칙

다음 사항을 반드시 준수한다.

1. 반드시 참조 영상을 직접 확인하고 분석한다.
2. 영상을 확인하지 못했다면 확인했다고 가정하거나 분석 결과를 만들어 내지 않는다.
3. 영상에서 실제로 확인한 사실과 개인적인 해석 및 아이디어를 구분한다.
4. 기존 기획서의 내용을 무조건 유지하지 않는다.
5. 반대로 참조 영상의 모든 요소를 무조건 프로젝트에 적용하지도 않는다.
6. 영상 분석과 프로젝트 방향 제안을 먼저 완료하고, 실제 개발이나 코드 수정은 진행하지 않는다.
7. 프로젝트의 최종 방향은 사용자 승인 후 확정한다.
8. 사용자의 승인 없이 프로젝트명, 핵심 컨셉, 기능, 기술 스택을 임의로 변경하지 않는다.

영상 접근이 불가능하다면 그 사실과 원인을 먼저 보고하고, 영상 파일이나 캡처 등 추가 자료를 요청한다. 이 경우 분석을 완료한 것처럼 진행하지 않는다.

## 3. 참조 영상 분석 항목

영상을 처음부터 끝까지 확인하고 다음 항목을 분석한다.

### A. 핵심 컨셉
- 영상이 전달하는 핵심 주제는 무엇인가?
- 시청자가 어떤 경험을 하게 되는가?
- 영상의 매력은 고양이 자체인가, 고양이의 행동인가, 배경과 공간인가?
- 단순한 감상형 콘텐츠인가, 직접 참여하는 인터랙티브 콘텐츠인가?
- 영상에서 가장 인상적인 요소는 무엇인가?

### B. 고양이의 행동과 생활
- 고양이는 어떤 행동을 하는가?
- 걷기, 산책, 탐험, 휴식, 낮잠, 그루밍, 놀이, 교감 등이 등장하는가?
- 고양이가 스스로 행동하는가, 사용자의 조작에 반응하는가?
- 행동이 자연스럽고 자율적인가?
- 고양이의 성격이나 개성이 표현되는가?

### C. 공간과 세계관
- 배경은 실내인가, 실외인가?
- 마을, 숲, 정원, 골목길, 공원 등 어떤 공간이 등장하는가?
- 공간은 현실적인가, 판타지적인가?
- 고양이가 자유롭게 이동할 수 있는 구조인가?
- 배경이 고양이의 행동과 어떤 관계를 맺는가?
- 추가적으로 확장할 수 있는 공간은 무엇인가?

### D. 카메라와 연출
- 카메라 시점은 1인칭인가, 3인칭인가?
- 고양이를 따라가는 카메라인가, 고정된 카메라인가?
- 카메라 움직임은 부드러운가?
- 고양이와 배경의 비율은 어떻게 구성되는가?
- 영상의 구도와 장면 전환은 어떤 특징이 있는가?

### E. 그래픽과 아트 스타일
- 3D인지 2D인지?
- 캐릭터 모델링의 특징은 무엇인가?
- 배경의 디테일과 표현 방식은 어떠한가?
- 색감, 조명, 그림자, 재질은 어떤 특징이 있는가?
- 전체적으로 사실적인가, 귀여운 스타일인가, 따뜻한 감성인가?
- 실제 구현에 참고할 만한 그래픽 요소는 무엇인가?

### F. 사운드와 분위기
- 배경음악이 사용되는가?
- 환경음과 효과음은 어떤 방식으로 표현되는가?
- 고양이의 울음소리나 골골송이 등장하는가?
- 사운드가 콘텐츠의 몰입감에 어떤 역할을 하는가?

## 4. 기존 프로젝트 기획과 비교

기존 CAT ADVENTURE 기획서를 기준으로 참조 영상과 비교한다.

기존 기획의 주요 요소는 다음과 같다.

- 브라우저 기반 3D 고양이 콘텐츠
- 고양이 외형 커스터마이징
- 마을과 숲을 중심으로 한 자유 탐험
- 고양이의 자율적인 생활과 행동
- 걷기, 앉기, 낮잠, 그루밍 등 자연스러운 행동
- 자동 생활 모드와 직접 조작 모드
- 카메라 추적 및 자유 회전
- 먹이와 간단한 상호작용
- 고양이 울음소리와 환경 사운드
- 편안하고 따뜻한 분위기의 가상 세계

각 항목을 다음 세 가지로 구분한다.

1. 유지: 기존 기획과 참조 영상의 방향이 일치하는 요소
2. 수정: 참조 영상의 특징을 반영하여 개선할 요소
3. 제거 또는 보류: 핵심 경험에 필요하지 않거나 우선순위가 낮은 요소

추가로 참조 영상에서 새롭게 발견한 기능이나 경험도 정리한다.

## 5. 새로운 프로젝트 컨셉 제안

영상 분석과 기존 기획 비교가 끝나면 새로운 프로젝트 컨셉을 제안한다.

다음 항목을 포함한다.

### A. 프로젝트 정체성
- 프로젝트를 한 문장으로 정의
- 사용자가 경험하게 될 핵심 가치
- 프로젝트가 일반적인 고양이 게임과 다른 점
- 가장 중요하게 전달해야 하는 감정

### B. 핵심 플레이 경험
사용자가 콘텐츠에 접속했을 때부터 종료할 때까지 어떤 경험을 하는지 구체적으로 설명한다.

예시:
- 고양이를 생성한다.
- 고양이와 함께 가상 세계에 들어간다.
- 고양이의 행동을 관찰하거나 직접 조작한다.
- 주변 공간을 탐험한다.
- 고양이와 상호작용한다.
- 편안하게 휴식하거나 풍경을 감상한다.

위 내용은 예시이며, 실제 참조 영상 분석 결과에 맞게 재구성한다.

### C. 핵심 기능 재정의
기존 기능을 그대로 나열하지 말고 새롭게 정의된 컨셉에 맞춰 기능을 분류한다.

- 반드시 필요한 핵심 기능
- 콘텐츠의 완성도를 높이는 보조 기능
- 추후 업데이트 기능
- 현재 프로젝트에서 제외할 기능

### D. 비주얼 방향
- 캐릭터 디자인
- 월드 및 배경 디자인
- 카메라 연출
- 조명 및 색감
- 애니메이션 스타일
- UI 및 UX 방향

### E. 확장 가능성
향후 맵, 캐릭터, 행동, 상호작용, 환경 변화 등을 어떤 방식으로 확장할 수 있는지 제안한다.

## 6. 프로젝트 제목 재검토

기존 CAT ADVENTURE라는 이름을 반드시 유지할 필요는 없다.

새롭게 정의된 컨셉에 적합한 프로젝트명을 제안한다.

제목 선정 기준:
- 이름만 봐도 콘텐츠의 성격을 직관적으로 이해할 수 있어야 한다.
- 고양이와 산책, 일상, 탐험, 휴식 등의 핵심 경험을 고려한다.
- 지나치게 추상적이거나 의미를 설명해야 하는 조어는 지양한다.
- 짧고 기억하기 쉬워야 한다.
- 영문으로 사용했을 때 자연스러워야 한다.
- 향후 브랜드명과 서비스명으로 활용할 수 있어야 한다.

최소 10개 후보를 제안하고 다음 내용을 함께 작성한다.

- 프로젝트명
- 이름의 의미
- 전달하는 분위기
- 프로젝트와 어울리는 이유

마지막으로 가장 적합한 TOP 3를 선정하고 각각의 장단점을 설명한다.

최종 이름은 사용자 승인 전까지 확정하지 않는다.

## 9. 최종 목표

이번 작업의 최종 목표는 단순히 기존 프로젝트에 기능을 추가하는 것이 아니다.

**참조 영상에서 느껴지는 매력과 경험을 파악하고, 이를 바탕으로 우리가 만들고 싶은 고양이 콘텐츠가 무엇인지 명확하게 정의하는 것이다.**

모든 분석과 제안이 끝나면 사용자에게 결과를 보고하고 승인을 기다린다.

사용자가 최종 방향을 승인한 이후에만 통합 기획서 수정과 실제 개발 단계로 넘어간다.
